# 📊 ASOS Fashion Brand Analysis Dashboard

A professional **Business Intelligence Dashboard** built with **Streamlit** to analyze ASOS fashion product data. The dashboard helps identify stockout trends, estimate potential revenue loss, and discover inventory optimization opportunities through interactive visualizations.

# 🎯 Project Objective

This project analyzes ASOS fashion product data to answer key business questions:

- Which brands experience the highest stockouts?
- How much revenue is potentially lost due to stock shortages?
- Which brands require inventory optimization?
- How do pricing and stock availability impact business performance?

The dashboard transforms raw data into actionable business insights for inventory and supply chain decision-making.

# ▶️ Installation

Clone the repository

```bash
git clone https://github.com/krutika-khenat/asos-stockout-analysis.git
```

Move into the project directory

```bash
cd asos-stockout-analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
